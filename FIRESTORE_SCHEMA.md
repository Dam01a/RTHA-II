# Firestore Schema

## `users/{uid}/emergencyContacts/{contactId}`
- `name` (string, required)
- `phone` (string, required, E.164 preferred)
- `email` (string | null)
- `relationship` (string, required)
- `createdAt` (timestamp, server)
- `updatedAt` (timestamp, optional, server)

## `users/{uid}/healthMetrics/{metricId}`
- `type` (string, required: `blood_pressure` | `heart_rate` | `blood_sugar` | `weight` | `temperature`)
- `recordedAt` (string, ISO-8601, required)
- `unit` (string | null, required for display)
- `value` (number | null, scalar metrics only)
- `systolic` (number | null, blood pressure only)
- `diastolic` (number | null, blood pressure only)
- `notes` (string | null)
- `createdAt` (timestamp, server)
- `updatedAt` (timestamp, server)

## `providers/{providerId}` (seeded directory)
- `name` (string, required)
- `specialty` (string, required)
- `location` (string, required — default clinic / address label)
- `phone` (string, optional)

## `users/{uid}/appointments/{appointmentId}`
- `title` (string, required)
- `date` (string, `YYYY-MM-DD`, required)
- `time` (string, `HH:mm`, required)
- `location` (string, required)
- `providerId` (string | null)
- `providerName` (string | null)
- `doctorName` (string | null, legacy display; usually same as provider)
- `reason` (string | null, required for new bookings in app validation)
- `visitType` (string | null: `in_person` | `virtual` | `follow_up`)
- `type` (string, required — category: checkup / specialist / lab / therapy / other)
- `notes` (string | null)
- `reminder` (boolean, required — aligned with in-app reminder intent)
- `reminderSmsEnabled` (boolean)
- `reminderStatus` (string: `pending` | `scheduled` | `sent` | `failed`)
- `createdAt` (timestamp, server)
- `updatedAt` (timestamp, server)

## `appointmentReminderQueue/{queueId}` (id: `{uid}_{appointmentId}`)
- `userId` (string, required)
- `appointmentId` (string, required)
- `phone` (string, required — from user profile)
- `message` (string, required)
- `sendAt` (timestamp, required)
- `status` (string: `pending` | `sent` | `failed`)
- `sentAt` (timestamp, optional, server)
- `failedAt` (timestamp, optional, server)
- `error` (string, optional)
- `updatedAt` (timestamp, server)

## `emergencyEvents/{eventId}`
- `userId` (string, required)
- `userEmail` (string | null)
- `timestamp` (string, ISO-8601, required)
- `locationShared` (boolean, required)
- `location` (map, optional)
  - `latitude` (number)
  - `longitude` (number)
  - `accuracyMeters` (number, optional)
  - `locationLink` (string)
- `message` (string, required)
- `dispatchResult` (map, required)
  - `status` ("sent" | "partial_failure" | "failed")
  - `contactedPhones` (array<string>)
  - `failedPhones` (array<string>)
- `createdAt` (timestamp, server)
